# RFID_DOOR LOCK
RFID Door Lock is an electronic door locking system using RFID technology with a servo motor as the locking mechanism. When a registered RFID card is tapped, the system recognizes the card and activates the servo to unlock the door, accompanied by a buzzer sound and LED indicator to indicate successful access. If an unregistered card is detected, the buzzer and LED remain active for a longer duration to indicate that access is denied.

Main components: RFID Module, Servo Motor, Buzzer, and LED.
